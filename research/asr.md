# Исследование: русский ASR и диаризация (август 2026)

## Батчевый ASR — вывод: GigaAM-v3 (SberDevices, MIT)
https://github.com/salute-developers/GigaAM — MIT, коммерческое ОК [точно]. 220M параметров,
v3 (12.2025): 700 тыс. ч предобучения. e2e-варианты дают пунктуацию/нормализацию из коробки.

WER v3 RNNT vs Whisper large-v3 [точно, офиц. evaluation.md]:
- Golos Farfield (дальнее поле!): **3.9 vs 16.4**
- OpenSTT phone calls: **17.4 vs 27.4**
- Callcenter: **9.5 (e2e-RNNT 12.6) vs ~19.4**
- Независимый бенчмарк alphacephei (12 сетов): GigaAM2 — 8.42% avg (лучший из открытых)
Whisper на русской шумной/телефонной речи хуже в 1.5–2 раза. Это решает выбор.

Скорость GigaAM: RTF ≈ 0.033 GPU (≈30× один поток, ONNX) [сторонний замер]; 4–6 ГБ VRAM на
воркер → на 24 ГБ GPU несколько воркеров, агрегированный RTFx ~100+ [оценка].

Запасные: faster-whisper large-v3-turbo batched — 41× на L4 [точно], 70–100× на 4090 [оценка],
VRAM 2.3–4.5 ГБ; T-one+LM для сильно телефонного звука (8.63% callcenter).

## Стриминговый ASR (этап 2) — вывод: T-one (Т-Банк, Apache 2.0)
https://github.com/voicekit-team/T-one — 71.6M, Conformer+CTC, обучен на 80 тыс. ч (телефония).
**Чанк 300 мс, эмиссия partial ~330 мс, полный пайплайн 1–1.2 с** (финализация: тишина 600 мс)
[точно]. TensorRT: A100 — 7833 потоков аудио; работает даже на CPU (4 ядра). Единственный
открытый русский стриминг с документированной задержкой. Whisper-стриминг-обёртки ~3.3 с — не
подходят. У GigaAM официального стриминга нет. SpeechKit streaming — managed-альтернатива без
публичных цифр задержки.

## Диаризация
- **pyannote community-1** (09.2025, CC-BY-4.0): DER лучше 3.1 (AMI 17.0, DIHARD-3 20.2);
  режим exclusive_speaker_diarization для склейки с ASR [точно]. pyannote 3.1 — MIT.
- Скорость pyannote: ~5–10× на T4/A10 наивно, до ~92× на A6000 при тюнинге [оценка, разброс].
- **NVIDIA Streaming Sortformer v2.1** (08.2025): стриминговая диаризация ≤4 спикеров,
  low-latency буфер 1.04 с, RTF 0.093; предупреждение о деградации на не-английском [точно].
  Для этапа 2 — кандидат, но с оговоркой про русский.
- SOTA-тренд: e2e диаризация + speaker-attributed ASR; у нас главный сигнал — асимметрия
  каналов бейджа, диаризация только дочищает.

## VAD: Silero VAD — MIT, российский, <1 мс на чанк 30 мс на 1 потоке CPU, модель 2 МБ [точно].
Стандарт индустрии. Идёт на шлюз/в облако; на ESP32 — простой энергетический гейтинг.

## Облачные ASR API (РФ) — почему НЕ подходят для батча
- Яндекс SpeechKit: ≈36 ₽/ч async [оценка, сходятся 2 источника]
- SaluteSpeech: 36 ₽/ч канал (0.01 ₽/с) + мин. платёж 15 000 ₽/мес [точно]
- 64 ч/мес на менеджера × 36 ₽ = **~2 300 ₽/мес = ~$28 — одна только транскрибация рвёт бюджет $15**.
- Self-hosted: ~0.3–1 ₽ за час аудио при хорошей загрузке GPU [оценка] → ~20–65 ₽/мес на менеджера.
  **В 35–100 раз дешевле API. Self-hosted ASR обязателен по экономике.**
