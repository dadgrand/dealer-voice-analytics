# Исследование: правовая база записи разговоров в шоуруме (РФ, август 2026)

## Ключевые тезисы
1. **Аудиозапись разговора = ПДн, но НЕ биометрия**, пока голос не используется для установления
   личности (ст. 11 152-ФЗ, оба условия одновременно; позиция РКН — письмо 29.10.2022 № 08-78032
   по фото, логика общепринята для голоса). → **Архитектурное ограничение: никакого voice-ID.**
   Диаризация по каналам/асимметрии, не по голосовым профилям. Иначе УЗ-1/УЗ-2 + штрафы 15–20 млн.
2. **Основание обработки клиентов**: связка «уведомление (таблички) + явное согласие отдельным
   документом (с 01.09.2025 — только обособленная форма!) + п. 5 ч. 1 ст. 6 (преддоговорные
   отношения) для реальных покупателей». Конклюдентное «вошёл после таблички = согласился» для
   системной аудиоаналитики — зона неопределённости, единственным основанием не делать.
   Для «зашедших посмотреть» без согласия — не хранить/не анализировать персонализированно.
3. **Локализация (ч. 5 ст. 18)**: весь конвейер — запись, STT, LLM, хранение — только в РФ.
   Зарубежные API (OpenAI и т.п.) для аудио/транскриптов = нарушение (1–6 млн ₽, повторно 6–18).
4. **Сотрудники**: запись законна при ЛНА (цели: контроль качества, обучение) + ознакомление под
   подпись (ст. 86–88, 21–22 ТК); практика: А33-6688/2014 (сверить номер). Использование записей
   только в заявленных целях. Ст. 74 ТК при изменении условий (уведомление за 2 мес).
5. **152.2 ГК**: разговор о покупке = договорные отношения, не «частная жизнь» (ВС РФ 35-КГ16-18).
   Но случайные спецкатегории (здоровье, семья) в записях — риск → фильтр/удаление фрагментов.
6. **Тайна связи (126-ФЗ) НЕ применяется** к живым разговорам (нет сети электросвязи) [точно].
   Если добавим телефонию — отдельная проработка.
7. **233-ФЗ (обезличивание, с 01.09.2025)**: маскирование ПИИ полезно, но из-под 152-ФЗ не выводит,
   пока есть обратная привязка (CRM). Возможна обязанность выгрузки обезличенных датасетов в НСУД.
8. **Штрафы (КоАП 13.11, ред. 420-ФЗ, с 30.05.2025, юрлицам)**: без согласия 300–700 тыс.;
   локализация 1–6 млн (повторно 6–18); утечка 1–10 тыс. субъектов = 3–5 млн; повторная утечка =
   оборотный 1–3% выручки (min 20 млн, max 500 млн); утечка биометрии 15–20 млн.
9. **Оператор обязан**: уведомление РКН (ст. 22), политика, ответственный, модель угроз,
   УЗ по ПП 1119 (целевой **УЗ-3** с запасом), меры по приказу ФСТЭК № 21, уведомление об утечке
   24 ч/72 ч. Лицензия ФСТЭК не нужна (обрабатываем свои ПДн), аттестация — только для ГИС.
10. **Облака РФ пригодны**: Яндекс/Selectel/VK/Cloud.ru — «облако 152-ФЗ» до УЗ-1 [точно].
    Обязателен договор поручения обработки (ч. 3 ст. 6). Разделённая ответственность.
11. **Ретенция**: типовой срок хранения аудио 3–6 мес (ч. 4 ст. 21 — удаление по достижении целей).

## Чек-лист внедрения (в документ, гл. 10)
1. Уведомление РКН (цели: контроль качества, аналитика; облако указано).
2. Пакет оператора: политика, приказ, модель угроз, акт УЗ-3, меры ФСТЭК №21, регламент 24/72.
3. Таблички «ведётся аудио- и видеозапись» + скрипт устного предупреждения менеджера.
4. Явное согласие клиента отдельным документом на этапе анкеты/сделки + п. 5 ч. 1 ст. 6.
5. Запрет voice-ID как архитектурное ограничение (зафиксировать в документации).
6. ЛНА для сотрудников + подписи + доп. соглашения (ст. 74 при необходимости).
7. Весь конвейер в РФ + договор поручения с облаком.
8. Ретенция: аудио 6 мес авто-удаление, маскирование ПИИ в транскриптах, фильтр спецкатегорий,
   RBAC + журналирование доступа.
9. Процедуры прав субъектов (запрос, отзыв согласия — 30 дней).
10. Финальная валидация пакета юристом по ПДн.

## Главные риски (в документ)
- Утечка массива записей → миллионные штрафы + оборотные при повторе. Записи = концентрат ПДн.
- Случайные спецкатегории в записях (здоровье) → 10–15 млн при утечке. Нужна политика удаления.
- Переквалификация в биометрию при voice-ID.
- «Табличка вместо согласия» — при жалобе посетителя ч. 1 13.11 (150–300 тыс.).
- Ст. 137 УК для должностных лиц при утечке личных подробностей.

Источники и даты — в отчёте агента; суммы сверены по двум источникам; нумерацию частей 13.11
свериться перед публикацией.
