# Исследование: компонентная база бейджа и площадочное железо (17.08.2026)

Курс: 80–82 ₽/$ (ЦБ 04–08.08.2026).

## Ключевые технические факты [точно]
- **ESP32-S3**: два I2S-контроллера, одна шина в std-режиме берёт 2 MEMS как стерео (L/R по WS).
- **Opus на ESP32-S3 реален**: esphome/micro-opus fixed-point @240 МГц, 16 кГц моно VOIP:
  complexity 0 → **4.9× реального времени**, c2 → 2.9×, c5 → 2.1×. Float в 4–6 раз медленнее — не брать.
- **Потребление** (даташит v2.2): запись Opus+SD, Wi-Fi off (modem-sleep 80–160 МГц) →
  **среднее ~45–70 мА @3.3В** → смена 11 ч = **500–800 мА·ч**. АКБ 103450 2000 мА·ч = запас >2×.
  Wi-Fi TX пик 283 мА (HT20 MCS7) — выгрузка 120–160 МБ/сутки занимает минуты, энергетически ничтожна.
- nRF5340: нет Wi-Fi, дороже ($5.22) — отвергнут (выгрузка 150 МБ по BLE нереалистична).
- INMP441 фактически EOL — в серию не закладывать. **ICS-43434** (SNR 64 дБА, AOP 120 дБ SPL) — выбор.
- eMMC вместо microSD смысла нет: дороже, чинить сложнее.
