5. Облачная архитектура и стек

5.1. Размещение

Всё, что касается персональных данных (аудио, транскрипты, разборы), живёт в российском облаке — это не предпочтение, а ч. 5 ст. 18 152-ФЗ (гл. 10). Основной контур — Selectel (выделенные GPU дешевле рынка, S3 2.29/1.14 ₽/ГБ, сегмент «облако 152-ФЗ» до УЗ-1) с почасовым бурстом GPU в immers.cloud; равноценные альтернативы — Яндекс Облако/VK Cloud (сводная таблица цен — приложение Б). Мультиклауд не городим: на нашем масштабе это усложнение без пользы, переезд страхуется тем, что весь стек — открытый софт в контейнерах поверх S3-совместимого API и PostgreSQL.

5.3. GPU-парк: главный расчётный узел

Три задачи делят GPU класса RTX 4090 (24 ГБ): диаризация (дорогая: RTFx≈15 консервативно), ASR (RTFx≈40 консервативно с батчингом) и LLM-разбор (T-Pro 2.0 32B AWQ: ~180–300 разговоров в GPU-час). Днём приоритет у диаризации+ASR (свежие разговоры), LLM-очередь дожёвывается ночью — GPU загружены равномерно, покупать отдельный LLM-парк не нужно. Закупка гибридная: постоянная подписка (выделенный сервер 56 900 ₽/мес Selectel / 29 000 ₽ HOSTKEY) под ровное основание нагрузки + почасовая аренда (82.76 ₽/ч immers.cloud) под субботние пики и рост. Прерываемые инстансы (скидки до 75% у Selectel) — кандидат после пилота; батч-пайплайн переживает вытеснение по построению (задания идемпотентны, ретраи дешевы). Полные цифры по обоим масштабам — гл. 8.

5.4. Мониторинг как продукт, а не приложение

  • Флот: % бейджей, вышедших на связь сегодня; % записанных смен (главная метрика приживаемости); батареи; очередь RMA. Алерты: «бейдж молчит 24 ч», «на площадке X доля записанных смен упала ниже 80%».
  • Пайплайн: лаг очередей по стадиям (выгрузка→сегментация→ASR→LLM→CRM), SLA-таймер «разговор → карточка» (цель: 95% в тот же день), глубина ретраев, стоимость GPU-часа факт/план.
  • Качество: WER-прокси (perplexity ASR, доля low-confidence), DER-выборки, доля разговоров без автосопоставления со сделкой (цель <15% после шага Б), доля отклонённых менеджерами сопоставлений.
